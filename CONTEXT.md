# FreeShape

Local, self-hostable parametric CAD modelled on Onshape's workflow. This glossary covers the Onshape-parity work: Documents, Derived, Variable Studios and mate connectors.

## Language

**Document**:
A folder that groups related tabs and carries their shared version history (git). The unit you open, version, branch and share.
_Avoid_: project, workspace (workspace means something else in Onshape)

**Tab**:
One editable item inside a Document: a Part Studio, Assembly, Drawing or Variable Studio. Stored as its own file and identified by a stable ID, not its file name.
_Avoid_: file, page

**Part Studio**:
A tab holding a feature list that builds one or more parts, sketches and planes.

**Assembly**:
A tab placing instances of parts and sketches and joining them with mates.

**Sketch instance**:
A Part Studio sketch placed in an Assembly through a Link, as a layout to mate parts to. It behaves as a part instance does: it can move, be fixed, be grouped, and be either end of a Mate. A Mate reaches it through a sketch point or line, or through a mate connector authored on the sketch.
_Avoid_: layout (the use, not the object), skeleton, sketch object

**Version**:
A named, immutable snapshot of a whole Document, made on purpose with "Create version" (a git commit plus tag). Saving does not make a Version.
_Avoid_: save, revision, commit (commit is the storage detail)

**Workspace**:
A line of editable work in a Document, branching from a Version; shown in the app and stored as a git branch.
_Avoid_: branch (in conversation; fine in code)

**Published output**:
What a tab offers to other tabs after it regenerates: parts, sketches, variables, mate connectors, each with a content hash.
_Avoid_: export (means writing a file)

**Link**:
A reference from one tab to another tab's published output, such as a Derived part, a variable used from a Variable Studio, or a part instance in an Assembly. Links form the graph that decides what regenerates after an edit.
_Avoid_: reference (reserved for picked faces, edges and regions inside a tab)

**Variable Studio**:
A tab holding named variables (name, expression, units) for other tabs to use.
_Avoid_: globals, parameters file

**Variable Studio reference**:
A feature placed in a Part Studio's or Assembly's feature list that brings in a Variable Studio's variables from that point on. A later local variable with the same name overrides it.
_Avoid_: import (means STEP import)

**Derived**:
A Part Studio feature that brings parts, sketches and mate connectors from another Part Studio through a Link, optionally placed by aligning mate connectors. It carries no variables; those cross tabs only through a Variable Studio reference.
_Avoid_: copy, insert

**Context**:
A frozen capture of an Assembly, taken from one part instance, that shows that part's neighbours inside its Part Studio at their mated positions so features can reference them. It changes only when the user updates it. A separate feature from Derived for the user; both use Links.
_Avoid_: in-context snapshot, shape binder (FreeCAD's name for the mechanism)

**Python feature**:
A Part Studio feature whose geometry is built by Python code with declared parameters, supplied by a Plugin. It builds through FreeShape's naming API, so its faces and edges get Element names like any built-in feature's.
_Avoid_: scripted feature, script, macro, FeatureScript

**Plugin**:
A folder that supplies Python features, Standard parts or both, identified by an id and a version. Some Plugins ship with FreeShape (gears, fasteners); others are installed by the user. Plugins load only from the installed plugin folder, never from a Document.
_Avoid_: addon, extension, workbench

**Standard part**:
A catalogue part such as a screw, nut or washer, generated by a Plugin from a type and parameters (standard, size, length) and inserted straight into an Assembly as a part instance. It has no Part Studio. It carries its own named mate connectors, computed from the same dimensions as its shape.
_Avoid_: standard content (Onshape's name), fastener (one kind of Standard part), library part

**Element name**:
A stable name for a face, edge or vertex, built from the history of the features that created and changed it. A picked reference stores its element name plus a geometric signature; the name is tried first.
_Avoid_: index, face number (indices change on every rebuild)

**Mate**:
A joint between two instances (part or sketch) in an Assembly, defined by one connector frame on each, that removes some of their six relative degrees of freedom.
_Avoid_: joint (FreeCAD's name), constraint (means sketch constraints)

**Mate value**:
How far one degree of freedom of a Mate has travelled from the pose where its two connectors are aligned, counted past a full turn (450°, not 90°). Stored in the Assembly.
_Avoid_: angle, position, offset (offset is a fixed setting of the Mate, not its travel)

**Relation**:
A rule tying the Mate value of one degree of freedom to another at a fixed ratio: gear, rack and pinion, screw or linear.
_Avoid_: gear mate, coupling, gear joint

## Relationships

- A **Document** contains one or more **Tabs**
- A **Tab** belongs to exactly one **Document**
- A **Document** has one or more **Workspaces**; each **Version** is made in one **Workspace**
- A **Link** within one **Document** is live by default: it follows the current **Workspace**. It can be pinned to a **Version** of the same **Document**, and then offers an update like a cross-Document **Link**
- A **Link** to another **Document** is pinned to a **Version** and offers an update when a newer one exists
- Variables cross tabs only through a **Variable Studio reference**, the whole Studio or a ticked subset; a later definition of the same name wins and the overridden one is marked. **Derived** carries none, as in Onshape
- A **Standard part** instance records its **Plugin**'s id and version, its type and its parameters; its shape is rebuilt from those, not stored. It exists only in an **Assembly** and is never **Published output** of a **Part Studio**
- A **Mate** reaches a **Standard part** through one of its named mate connectors, so the **Mate** survives a change of size or length
- Inserting a **Standard part** onto several holes makes one independent instance and one fastened **Mate** per hole; nothing groups them afterwards
- A **Context** is a feature in a **Part Studio**'s feature list; its bodies can be picked by later features but are never **Published output**
- A **Context** belongs to one **Part Studio** and is captured from one part instance in one **Assembly**
- A **Context** stores the neighbours' shapes, **Element names** and positions; it is not a live **Link** and regenerates nothing until the user updates it
- A **Mate** has one **Mate value** per degree of freedom it leaves free; fastened and ball Mates have none
- A **Relation** refers to one degree of freedom of each of two **Mates** (a screw **Relation**: two degrees of freedom of one cylindrical **Mate**); it never refers to parts or connectors directly
- A **Relation** is distinct from a gear **Python feature**: the Relation ties rotations together, the Python feature makes tooth geometry
- A **Sketch instance** is a live **Link** to a sketch in a **Part Studio** of the same **Document**; it is captured by a **Context** like any other neighbour
- A **Mate** reaches a **Sketch instance** through a sketch point or line, keyed by the sketch's own entity id and a role (point, end, midpoint, centre), or through a mate connector authored on the sketch; an **Element name** is not used for sketch geometry
- A **Sketch instance** offers the **Part Studio** origin as a mate connector; fastening that to the **Assembly** origin is how a layout is pinned
- Merging **Workspaces** works tab by tab: a **Tab** changed on both sides is chosen whole, never mixed

## Flagged ambiguities

- "document" in the code (`freeshape/document.py`) means a single Part Studio tab, not the folder-level Document defined here. The class there is `PartStudioDoc`; `Document` stays as an alias for the old name, and the `document` file format and migration chain keep their name. The folder-level Document is `FolderDocument`.

## Decisions

2026-11-12: after the Derived spike, Adam reaffirmed 0001 over a single nested-JSON file; the self-hosted cloud version will store Documents in a database instead (a future ADR will supersede 0001 for that deployment, keeping one record per Tab).

2026-11-13: after the Foundations run, Adam chose Onshape's model for variables: Derived carries no variables (reversing the 2026-11-12 grill), and a qualified name such as `#partstudio1.w` was dropped. A value that exists only in a Part Studio cannot be shared with another tab. Cross-Document sources are in the top-down design PRD. On a severed solid, a stamping feature stamps every sibling piece (F1.1, option A).

2026-11-13: Standard parts are generated by code ported from the FreeCAD Fasteners workbench (LGPL-2.1) and ship as a bundled Plugin (`fasteners`). Each instance records the Plugin's id and version, its type and its parameters. McMaster-Carr and other vendor STEP files are not shipped: their terms bar redistribution.
